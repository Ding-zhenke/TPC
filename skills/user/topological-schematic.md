# 拓扑光子晶体结构示意图：TPC 统一要求

适用于器件的俯视结构图、结构预测图和修改审批图。参考视觉语法见 [BA Σ 合路器审批图](references/ba-sigma-approval.png)；借鉴其 A/B 晶相、黑色路径、编号节点、尺寸箭头和独立图例，**不照搬该器件的几何、数值或拥挤排版**。已有历史图只是待核对资料，不自动视为参数真值。

建模前的快速相区预检图只需核对两相孔型、路径、端口与视角；用于交流或交付的完整结构图再执行下述节点、尺寸和版式要求。

## 先确定事实

1. 从目标版本的建模源、参数表或经确认的设计文档读取晶格常数 `a`、孔尺寸/朝向、板边界、相区、路径、端口、透镜、调制/吸收/电极几何。图与模型共用一套参数及坐标变换；不得凭旧图描摹或自行补尺寸。
2. 先写清 **A/B（或 P1/P2）与孔大小、上下孔朝向、拓扑序的对应关系**，再上色。相名是物理定义，不能按“上方是 A、下方是 B”或按旧图颜色猜。端口 `P1/P2` 与相名、路径节点 `P01/P02` 分开解释。
3. 对多支路器件，列出每条有向路径及合流/分叉点；节点 ID 与唯一坐标、段长对应。无法从源文件证实的尺寸标为“待确认”，不伪造数字。

## 固定视觉语法

| 对象 | 默认表示 | 必须传达的信息 |
|---|---|---|
| A 相 | 淡粉底 `#f5e1e7`、粉色孔 `#e8718c` | 区内直接标 `A`，图例写孔型定义 |
| B 相 | 淡绿底 `#e5efe7`、绿色孔 `#5fa97c` | 区内直接标 `B`，图例写孔型定义 |
| 晶体板外轮廓 | 红色实线 `#e52b2f` | 仅表示晶体板边界；硅填充/金属另有边界 |
| 拓扑域壁/传输路径 | 深灰黑实线 `#17191c`，置于晶格上层 | 起点、终点、箭头、分叉与合流一眼可追踪 |
| 输入与行波方向 | 输入 1 深蓝 `#1f4e79`，输入 2 棕 `#8a4f20` 箭头 | 端口名、传播方向；不要与域壁线混成一种符号 |
| 调制/吸收区 | 中性灰；吸收区用斜线纹 | 有别于晶相，写出范围和变量 |
| 椭圆透镜 | 浅青绿底、深绿 `#07956b` 外轮廓 | 标拼接点、角度、焦点或主要轴长（存在时） |
| 电极/其他材料 | 另选高对比色或纹理，并单列图例 | 不借用 A/B 相色暗示晶相 |

颜色同时配字母、孔型或纹理，保证黑白打印仍能分辨。保持同一版本内同一语义同色；不同视图复用同一图例术语。晶格孔可在主图降对比，界面附近保持足够细节，密集处加局部放大图，不能让孔线盖住路径和标注。

## 图面与标注

- 主图用真实坐标的俯视图，`x/y` 轴及单位明确，等比例显示；厚度、PIN 分层和上下电极另用 `z` 剖面/小图表达。若局部为概念示意，显著写“非按比例”。
- 排版按“标题与视角 → 主图 → 图例/参数框 → 必要的节点坐标表”组织。长公式、工艺说明移至图外说明区；主图内只保留相名、端口、关键节点、路径、关键尺寸。文字与孔、路径、箭头不相压；最终使用尺寸下文字仍清晰，正文/节点一般不低于 8 pt。
- 每个关键拐点、支路连接点、调制起止点、合流点、透镜拼接点采用**唯一编号**（例如 `P01`…）；在点位画标记，标签白底或引线，编号按各支路的传播顺序解释。端口编号沿用模型，避免与节点号混淆。节点多时配坐标表（`a` 和 `mm`）而非把坐标塞进主图。
- 关键长度/宽度/角度都用尺寸界线、双端箭头与变量标注，如 `$L_{\mathrm{mod}}=N_{\mathrm{mod}}a=\cdots\,\mathrm{mm}$`。标清总长、支路段长、调制区、吸收块尺寸、必要的间距及透镜参数；只标与当前设计有关的尺寸，避免重复。变量和单位与模型参数同名同值，`a` 换算使用该版本实际取值。
- 可见边界实线、隐藏边界虚线、中心/对称线点划线、尺寸线细实线。路径线优先级高于晶格，尺寸线不冒充路径。标题或脚注写明版本、视角、图的用途（结构预测/修改审批/最终结构），不把示意图当仿真结果。

## 实施与交付检查

优先以 Python/Matplotlib 和现有 TPC 绘图函数生成可复现源文件；中文使用 `mesh_grid.plotting.chinese_plot_style(..., strict=True)`。结构图同时交付源文件、PNG（至少 180 dpi）和 SVG/PDF；需要审批节点时另存节点坐标表。绘图前后核对相区孔型、板/透镜几何、端口、节点坐标和标注长度与目标模型一致。

交付前按最终展示尺寸目视检查：① 两相可辨且图例定义正确；② 从每个输入可沿箭头走到输出；③ 节点编号唯一、位置可找、分支顺序明确；④ 关键长度有变量与单位且数值可由参数重算；⑤ 无遮挡、裁切、缺字或颜色语义冲突。未通过则调整主图、图外说明或局部放大图后重新导出。
