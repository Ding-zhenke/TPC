## 七、补充：坐标系统统一设计（P0 架构级，编号 20）

> 本节为针对性补充：预览阶段的
> `path_points`
> （三角晶格坐标）和 CST 阶段的
> `(px, py)`
> （直角坐标）本质上是同一条路径的两种表示，当前代码手动维护两套，是连接性差和出错的核心根源之一。

### 7.1 问题分析：两套坐标的对应关系

**预览阶段**（matplotlib）：路径用三角晶格坐标 `(r, c)` 表示，通过 `path_loc_to_xy()` 转直角坐标绘图。

转换公式（来自 `mesh_grid/tri_grid/core.py:600`）：



```
x = c \\\* a + r \\\* (a/2)

y = r \\\* (a/2 \\\* √3)
```

其中 `e1 = (a, 0)` 为列方向基向量，`e2 = (a/2, a/2*√3)` 为行方向基向量。

**CST 阶段**：路径点用直角坐标参数 `(px, py)` 表示，手动写 CST 表达式。

以直波导 `AB_feed.ipynb` 为例：



| 路径点  | 预览 (r, c)           | 预览转 (x, y)                     | CST 表达式                              | CST 计算结果                       |
| ---- | ------------------- | ------------------------------ | ------------------------------------ | ------------------------------ |
| 起点   | (0, 0)              | (0, 0)                         | `px1=0, py1=0`                       | (0, 0)                         |
| 拐点 1 | (0, x1=18)          | (18a, 0)                       | `px2=x1*a, py2=0`                    | (18a, 0)                       |
| 拐点 2 | (-y1=-14, x1+y1=32) | (32a-7a, -7a√3) = (25a, -7a√3) | `px3=px2+y1*a/2, py3=-y1*a/2*sqr(3)` | (18a+7a, -7a√3) = (25a, -7a√3) |

以 180° 透镜 `Ant1_grid_circle.ipynb` 验证：



* 预览 path 点 `(r=14, c=4)` → x = 4a + 14*a/2 = 11a，y = 14*a√3/2 = 7a√3

* CST `px3 = px2 - y1*a/2 = 18a - 7a = 11a`，`py3 = y1*a/2*sqr(3) = 7a√3`

**完全吻合。** 结论：`path_points` 和 `(px, py)` 是同一条路径的两套表示，当前代码等价于把同一份数据写了两遍、算了两遍。

### 7.2 为什么这是核心问题



1. **重复劳动**：每条路径的每个拐点都要在预览写一次 `(r,c)`，在 CST 再写一次 `px/py` 表达式

2. **极易出错**：拐弯处的 `px3 = px2 ± y1*e1`、`py3 = ± y1*e2` 符号容易搞反（AB/BA 型、120°/180°/240° 拐弯符号都不同）

3. **不同步**：改了预览的 path 后，忘记同步改 CST 的 px/py，导致预览和模型不一致

4. **无法参数化**：想做路径优化（遗传算法调拐点位置）时，需要同时维护两套变量

5. **区域边界重复**：`xmax`、`ymax_up`、`ymax_dn`、`xup`、`yup`、`ydn` 等也是从 path 和网格范围手动推导的，同样可以自动计算

### 7.3 统一方案：`TopoPath` 类

**核心思想**：只维护一套三角晶格坐标 `path_lattice = [(r,c), ...]`，所有直角坐标（预览用 + CST 用）全部自动推导。



```
\\# topo\\\_path.py — 统一坐标管理

import numpy as np

class TopoPath:

\&#x20;   """

\&#x20;   拓扑路径统一坐标管理。

\&#x20;   唯一数据源是三角晶格坐标 (r, c)，直角坐标自动推导。

\&#x20;   """

\&#x20;   def \\\_\\\_init\\\_\\\_(self, path\\\_lattice, a, name='path'):

\&#x20;       """

\&#x20;       参数:

\&#x20;           path\\\_lattice: (N,2) array，每行是 (r, c) 三角晶格坐标

\&#x20;           a: 晶格常数

\&#x20;           name: 路径名称（用于 CST 参数前缀）

\&#x20;       """

\&#x20;       self.path\\\_lattice = np.array(path\\\_lattice, dtype=int)

\&#x20;       self.a = a

\&#x20;       self.name = name

\&#x20;       # 预计算直角坐标（float，用于 matplotlib 预览）

\&#x20;       self.xy = self.\\\_lattice\\\_to\\\_xy(self.path\\\_lattice, a)

\&#x20;   # ---- 坐标转换（与 path\\\_loc\\\_to\\\_xy 完全一致）----

\&#x20;   @staticmethod

\&#x20;   def \\\_lattice\\\_to\\\_xy(path, a):

\&#x20;       """(r,c) → (x,y)，物理坐标（float）"""

\&#x20;       x = path\\\[:, 1] \\\* a + path\\\[:, 0] \\\* (a / 2)

\&#x20;       y = path\\\[:, 0] \\\* (a / 2 \\\* np.sqrt(3))

\&#x20;       return np.column\\\_stack((x, y))

\&#x20;   def \\\_lattice\\\_to\\\_cst\\\_expr(self, r, c):

\&#x20;       """(r,c) → CST 表达式字符串 (px, py)，支持参数化"""

\&#x20;       # x = c\\\*a + r\\\*a/2

\&#x20;       if r == 0:

\&#x20;           px = f'{c}\\\*a'

\&#x20;       elif c == 0:

\&#x20;           px = f'{r}\\\*a/2'

\&#x20;       else:

\&#x20;           px = f'{c}\\\*a+{r}\\\*a/2'

\&#x20;       # y = r\\\*a/2\\\*sqr(3)

\&#x20;       py = '0' if r == 0 else f'{r}\\\*a/2\\\*sqr(3)'

\&#x20;       return px, py

\&#x20;   # ---- 对外接口 ----

\&#x20;   def get\\\_xy(self):

\&#x20;       """返回直角坐标 (N,2)，用于 matplotlib 预览"""

\&#x20;       return self.xy

\&#x20;   def auto\\\_define\\\_cst\\\_params(self, app, prefix=None):

\&#x20;       """

\&#x20;       自动在 CST 中定义所有路径点的 px/py 参数。

\&#x20;       例如 path 有 3 个点，则在 CST 中创建：

\&#x20;           p1x, p1y, p2x, p2y, p3x, p3y

\&#x20;       """

\&#x20;       if prefix is None:

\&#x20;           prefix = self.name

\&#x20;       for i, (r, c) in enumerate(self.path\\\_lattice):

\&#x20;           px, py = self.\\\_lattice\\\_to\\\_cst\\\_expr(r, c)

\&#x20;           app.para(f'{prefix}{i+1}x', px)

\&#x20;           app.para(f'{prefix}{i+1}y', py)

\&#x20;   def get\\\_cst\\\_point(self, idx):

\&#x20;       """获取第 idx 个点的 CST 参数名元组 ('p1x', 'p1y')"""

\&#x20;       return f'{self.name}{idx+1}x', f'{self.name}{idx+1}y'

\&#x20;   def get\\\_bounding\\\_box(self, margin\\\_c=1, margin\\\_r=1):

\&#x20;       """

\&#x20;       从路径自动推导边界范围（替代手动计算 xmax/ymax\\\_up/ymax\\\_dn）。

\&#x20;       返回 (xmin, xmax, ymin, ymax) 的 CST 表达式或 float。

\&#x20;       """

\&#x20;       r\\\_min = self.path\\\_lattice\\\[:, 0].min() - margin\\\_r

\&#x20;       r\\\_max = self.path\\\_lattice\\\[:, 0].max() + margin\\\_r

\&#x20;       c\\\_min = self.path\\\_lattice\\\[:, 1].min() - margin\\\_c

\&#x20;       c\\\_max = self.path\\\_lattice\\\[:, 1].max() + margin\\\_c

\&#x20;       # 四个角的 (r,c)

\&#x20;       corners = \\\[(r\\\_min, c\\\_min), (r\\\_min, c\\\_max), (r\\\_max, c\\\_min), (r\\\_max, c\\\_max)]

\&#x20;       xy\\\_corners = self.\\\_lattice\\\_to\\\_xy(np.array(corners), self.a)

\&#x20;       return (xy\\\_corners\\\[:, 0].min(), xy\\\_corners\\\[:, 0].max(),

\&#x20;               xy\\\_corners\\\[:, 1].min(), xy\\\_corners\\\[:, 1].max())

\&#x20;   def \\\_\\\_len\\\_\\\_(self):

\&#x20;       return len(self.path\\\_lattice)

\&#x20;   def \\\_\\\_getitem\\\_\\\_(self, idx):

\&#x20;       return self.path\\\_lattice\\\[idx]
```

## 八、智能化增强设计（P0，让建模从 "写代码" 变成 "填配置"）

### 8.2 声明式路径 DSL（比手写 (r,c) 列表更直观）

当前定义路径需要手算每个拐点的 `(r,c)`：



```
path = TopoPath(\[(0, -1), (0, 18), (14, 4)], a=a)  # 要想清楚 14 和 4 怎么来的
```

智能化后用链式 DSL，只说 "走多远、转多少度"：



```
from topo\_path import TopoPath

\# 直波导：从(0,-1)出发，沿列方向直走18格

path = (TopoPath.builder(a)

&#x20;       .start(0, -1)

&#x20;       .move(steps=19, direction='c')   # 沿列方向走19格（含起点）

&#x20;       .build())

\# 120° 拐弯天线：直走18格 → 转120° → 再走4格

path = (TopoPath.builder(a)

&#x20;       .start(0, -1)

&#x20;       .move(steps=19, direction='c')

&#x20;       .turn(angle=120)                 # 自动计算拐点的 (r,c)

&#x20;       .move(steps=5, direction='along') # 沿转弯后方向走5格

&#x20;       .build())

\# 180° 透镜：直走18 → 转60° → 走14 → 转60° → 走4

path = (TopoPath.builder(a)

&#x20;       .start(0, -1)

&#x20;       .move(19, 'c')

&#x20;       .turn(60).move(15, 'along')

&#x20;       .turn(60).move(5, 'along')

&#x20;       .build())
```

`turn(angle)` 内部自动根据当前方向和角度计算下一个拐点的 `(r,c)`，用户不需要手算 `y[0]` 和 `x[0]-y[0]`。

**Builder 实现要点**：



```
class TopoPathBuilder:

&#x20;   # 三角晶格的6个方向（单位向量 (dr, dc)）

&#x20;   DIRECTIONS = {

&#x20;       'c':   (0, 1),    # 沿列正方向

&#x20;       '-c':  (0, -1),   # 沿列负方向

&#x20;       'r':   (1, 0),     # 沿行正方向

&#x20;       '-r':  (-1, 0),    # 沿行负方向

&#x20;       'rc':  (1, 1),     # 斜向

&#x20;       '-rc': (-1, -1),

&#x20;   }

&#x20;   def turn(self, angle):

&#x20;       """根据当前方向和转角，更新当前方向向量"""

&#x20;       # angle ∈ {60, 120, 180, 240, 300}

&#x20;       # 在6个方向中旋转

&#x20;       dirs = \[(0,1), (1,1), (1,0), (0,-1), (-1,-1), (-1,0)]

&#x20;       idx = dirs.index(self.\_current\_dir)

&#x20;       new\_idx = (idx + angle // 60) % 6

&#x20;       self.\_current\_dir = dirs\[new\_idx]

&#x20;       return self
```

### 8.5 TopoModeler 智能推断：用户不指定的，系统自动猜

`TopoModeler` 的核心价值是 "智能推断"—— 以下信息用户不需要手动指定：



| 推断项       | 推断逻辑                                                      |
| --------- | --------------------------------------------------------- |
| 拓扑相 AB/BA | 波导默认 AB，天线默认 BA；可被用户参数覆盖                                  |
| 端口数量      | path 有 2 个端点 → 2 端口（波导）；path 有 1 个馈电端 + 1 个辐射端 → 1 端口（天线） |
| 端口位置      | 自动在 path 起点 / 终点的波导端面上 pick\_face                         |
| 监视器类型     | 波导默认 E 场；天线自动加 Farfield                                   |
| 边界范围      | 从 path 的 bounding box + margin 自动推导                       |
| 光子晶体阵列范围  | 从基板区域自动推导 xup/yup/ydn                                     |
| 频率范围      | 从晶格常数 a 自动估算工作频段（a≈0.2425 → \~300GHz）                     |
| 网格精度      | 从最小特征尺寸（小孔 l2=0.35a）自动建议网格步长                              |

**智能推断的实现**：



```
class TopoModeler:

&#x20;   def \_\_init\_\_(self, template\_cst='tmp.cst'):

&#x20;       self.app = setup(template\_cst)

&#x20;       self.path = None

&#x20;       self.topology = None

&#x20;       self.\_params = {}

&#x20;       self.\_built = False

&#x20;   def set\_path(self, path):

&#x20;       self.path = path

&#x20;       # 自动推断模型类型

&#x20;       self.\_infer\_model\_type()

&#x20;   def \_infer\_model\_type(self):

&#x20;       """从 path 形状推断是波导还是天线"""

&#x20;       if len(self.path) <= 2:

&#x20;           self.model\_type = 'waveguide'   # 直线路径 → 波导

&#x20;       else:

&#x20;           self.model\_type = 'antenna'      # 有拐弯 → 天线

&#x20;       # 自动推断默认拓扑相

&#x20;       if self.topology is None:

&#x20;           self.topology = 'AB' if self.model\_type == 'waveguide' else 'BA'

&#x20;   def add\_ports(self, auto=True):

&#x20;       """自动添加端口"""

&#x20;       if not auto:

&#x20;           return  # 用户手动添加

&#x20;       if self.model\_type == 'waveguide':

&#x20;           # 波导：两端口，在波导端面 pick\_face

&#x20;           self.app.pick\_face('wg1', '10')   # 面编号可从模板配置中读取

&#x20;           self.app.add\_port(1)

&#x20;           self.app.pick\_face('wg1', '22')

&#x20;           self.app.add\_port(2)

&#x20;       elif self.model\_type == 'antenna':

&#x20;           # 天线：单端口，在馈电端面

&#x20;           self.app.pick\_face('feed2', '5')

&#x20;           self.app.add\_port(1, shield='electric')

&#x20;   def configure\_solver(self, freq\_range=None, monitors=None, \*\*kwargs):

&#x20;       """智能配置求解器"""

&#x20;       if freq\_range is None:

&#x20;           # 从晶格常数自动估算

&#x20;           a = self.\_params.get('a', 0.2425)

&#x20;           f\_center = 300  # a=0.2425 对应 \~300GHz

&#x20;           freq\_range = (f\_center - 20, f\_center + 80)

&#x20;       if monitors is None:

&#x20;           monitors = ('E', 'Farfield') if self.model\_type == 'antenna' else ('E',)

&#x20;       # ... 调用底层 configure\_solver\_default
```

### 8.8 自动命名管理：避免 CST 中 solid 名称冲突

当前代码中 solid 名称（`g1A`, `feed1`, `wg1` 等）是手写的，多次建模或复杂结构容易冲突。引入 `NameManager`：



```
class NameManager:

&#x20;   """CST solid 名称自动管理，保证唯一且有意义"""

&#x20;   def \_\_init\_\_(self):

&#x20;       self.\_names = {}

&#x20;       self.\_counters = {}

&#x20;   def get(self, prefix):

&#x20;       """获取一个唯一名称，如 'substrate\_1', 'crystal\_A\_2'"""

&#x20;       idx = self.\_counters.get(prefix, 0) + 1

&#x20;       self.\_counters\[prefix] = idx

&#x20;       name = f'{prefix}\_{idx}'

&#x20;       self.\_names\[name] = prefix

&#x20;       return name

&#x20;   def alias(self, name, alias):

&#x20;       """给名称起别名，方便后续引用"""

&#x20;       self.\_names\[alias] = name
```

建模时：




> 本节给出 `topo_path.py` 的完整、可运行实现。代码基于 `path_loc_to_xy` 的实际转换公式，6 个晶格方向的物理角度已逐点验证（见 9.1）。保存为 `topo_path.py` 后即可 `from topo_path import TopoPath, TopoPathBuilder` 使用。

### 9.1 数学基础（已验证）

三角晶格坐标 `(r, c)` → 物理坐标 `(x, y)` 的转换公式（与 `mesh_grid/tri_grid/core.py:600` 的 `path_loc_to_xy` 完全一致）：

```
x = c * a + r * (a/2)
y = r * (a/2 * √3)
```

6 个晶格方向（逆时针从 0° 开始）的 `(dr, dc)` 向量及对应物理角度：

| 索引 | 角度 | (dr, dc) | 物理位移 (x, y) | 方向名 |
|------|------|----------|-----------------|--------|
| 0 | 0° | (0, +1) | (a, 0) | +c（列正方向） |
| 1 | 60° | (+1, 0) | (a/2, a√3/2) | +r（行正方向） |
| 2 | 120° | (+1, -1) | (-a/2, a√3/2) | rc（斜左上） |
| 3 | 180° | (0, -1) | (-a, 0) | -c（列负方向） |
| 4 | 240° | (-1, 0) | (-a/2, -a√3/2) | -r（行负方向） |
| 5 | 300° | (-1, +1) | (a/2, -a√3/2) | -rc（斜右下） |

`turn(angle)` 的本质：在 6 个方向中旋转 `angle / 60` 步。例如 `turn(120)` = 索引 +2，从 0° (0,+1) 转到 120° (+1,-1)。

**验证**：从 (0, 18) 沿 120° 方向走 14 步 → (0+14*1, 18+14*(-1)) = (14, 4)，与原代码 `Ant1_grid_circle.ipynb` 中 path 的第三个拐点 `(y[0], x[0]-y[0]) = (14, 4)` 完全一致。

### 9.2 完整实现代码（topo_path.py）

```python
# -*- coding: utf-8 -*-
"""
topo_path.py — 拓扑光子晶体路径统一管理与声明式 DSL

唯一数据源是三角晶格坐标 (r, c)，所有直角坐标（matplotlib 预览 + CST 表达式）
全部自动推导，消除 path_points 和 (px,py) 两套坐标的重复维护。

用法:
    >>> from topo_path import TopoPath
    >>> path = (TopoPath.builder(a=0.2425)
    ...         .start(0, -1)
    ...         .move(19, 'c')
    ...         .turn(120)
    ...         .move(14, 'along')
    ...         .build())
    >>> path.xy          # 直角坐标 (N, 2)
    >>> path.preview()   # matplotlib 预览
    >>> path.auto_define_cst_params(app)  # 自动在 CST 中定义 p1x,p1y,...
"""

import numpy as np
import matplotlib.pyplot as plt
from typing import List, Tuple, Optional, Union


# ============================================================
# 方向常量：6 个晶格方向，逆时针从 0° 开始
# ============================================================
# 每个元素是 (dr, dc)，对应物理角度 = index * 60°
DIRECTIONS = [
    (0, 1),    # 0°   — +c
    (1, 0),    # 60°  — +r
    (1, -1),   # 120° — +r, -c
    (0, -1),   # 180° — -c
    (-1, 0),   # 240° — -r
    (-1, 1),   # 300° — -r, +c
]

DIRECTION_NAMES = ['+c', '+r', '+r-c', '-c', '-r', '-r+c']

# 方向名 → 索引的映射
_NAME_TO_IDX = {
    'c': 0, '+c': 0, 'c+': 0,
    'r': 1, '+r': 1, 'r+': 1,
    'rc': 2, 'r+c-': 2, '+r-c': 2,
    '-c': 3, 'c-': 3,
    '-r': 4, 'r-': 4,
    '-rc': 5, 'r-c+': 5, '-r+c': 5,
}


def _resolve_direction(direction) -> Tuple[int, int]:
    """
    将方向参数解析为 (dr, dc)。
    支持: 'along'/None（调用方处理）、'c'/'r'/'rc' 等名称、(dr,dc) tuple。
    """
    if direction is None or direction == 'along':
        return None  # 表示沿当前方向，由调用方处理
    if isinstance(direction, str):
        key = direction.strip().lower()
        if key in _NAME_TO_IDX:
            return DIRECTIONS[_NAME_TO_IDX[key]]
        raise ValueError(f"未知方向名 '{direction}'，支持: {list(_NAME_TO_IDX.keys())}")
    if isinstance(direction, (tuple, list)) and len(direction) == 2:
        dr, dc = int(direction[0]), int(direction[1])
        if (dr, dc) not in DIRECTIONS:
            raise ValueError(f"方向向量 ({dr},{dc}) 不是三角晶格的 6 个主方向之一")
        return (dr, dc)
    raise ValueError(f"无法解析方向: {direction!r}")


def _direction_to_index(dr: int, dc: int) -> int:
    """(dr,dc) → 方向索引 (0-5)"""
    return DIRECTIONS.index((dr, dc))


# ============================================================
# TopoPathBuilder — 声明式构建器
# ============================================================
class TopoPathBuilder:
    """
    链式构建器，用 .start().move().turn().build() 定义拓扑路径。
    用户不需要手算每个拐点的 (r,c)，只说"走多远、转多少度"。
    """

    def __init__(self, a: float, name: str = 'path'):
        self.a = a
        self.name = name
        self._points: List[Tuple[int, int]] = []
        self._current_r: Optional[int] = None
        self._current_c: Optional[int] = None
        self._current_dir: Optional[Tuple[int, int]] = None
        self._dirty_turn: bool = False  # turn 之后是否还没 move

    # ---- 核心链式方法 ----

    def start(self, r: int, c: int, direction=(0, 1)):
        """
        设置路径起点。
        direction: 初始行进方向，默认 +c（0°，从左到右）。
        """
        self._points = [(int(r), int(c))]
        self._current_r, self._current_c = int(r), int(c)
        self._current_dir = _resolve_direction(direction) or (0, 1)
        self._dirty_turn = False
        return self

    def move(self, steps: int, direction='along'):
        """
        从当前位置沿指定方向移动 steps 格，将新位置加入路径。

        参数:
            steps: 移动的格点数（正整数）
            direction: 'along'（当前方向）/ 'c'/'r'/'rc' 等名称 / (dr,dc) tuple
        """
        if self._current_r is None:
            raise RuntimeError("请先调用 .start(r, c) 设置起点")
        if steps <= 0:
            return self  # 0 步不产生新点

        dr, dc = self._resolve_move_direction(direction)
        new_r = self._current_r + steps * dr
        new_c = self._current_c + steps * dc
        new_point = (new_r, new_c)

        # 避免重复点（与上一个点相同则跳过）
        if not self._points or new_point != self._points[-1]:
            self._points.append(new_point)

        self._current_r, self._current_c = new_r, new_c
        self._current_dir = (dr, dc)
        self._dirty_turn = False
        return self

    def turn(self, angle: int):
        """
        旋转当前行进方向，不移动。
        angle: 60 的整数倍，正值逆时针，负值顺时针。
               常用: 60, 120, 180, 240, 300, -60, -120
        """
        if self._current_dir is None:
            raise RuntimeError("请先调用 .start() 设置初始方向")
        if angle % 60 != 0:
            raise ValueError(f"转角必须是 60° 的整数倍，收到 {angle}°")
        idx = _direction_to_index(*self._current_dir)
        new_idx = (idx + angle // 60) % 6
        self._current_dir = DIRECTIONS[new_idx]
        self._dirty_turn = True
        return self

    def line_to(self, r: int, c: int):
        """
        直接移动到指定 (r,c)，自动推断并更新行进方向。
        当目标点不在 6 个主方向上时发出警告（仍接受，但 turn() 将不可用）。
        """
        if self._current_r is None:
            raise RuntimeError("请先调用 .start(r, c) 设置起点")
        dr = int(r) - self._current_r
        dc = int(c) - self._current_c
        if dr == 0 and dc == 0:
            return self  # 同一点，跳过
        # 尝试推断方向
        gcd = abs(np.gcd(dr, dc)) if (dr != 0 or dc != 0) else 1
        unit_dr, unit_dc = dr // gcd, dc // gcd
        if (unit_dr, unit_dc) in DIRECTIONS:
            self._current_dir = (unit_dr, unit_dc)
        else:
            import warnings
            warnings.warn(f"从 ({self._current_r},{self._current_c}) 到 ({r},{c}) "
                          f"的方向 ({unit_dr},{unit_dc}) 不在 6 个主方向上，"
                          f"后续 turn() 可能不准确")
            self._current_dir = None
        new_point = (int(r), int(c))
        if new_point != self._points[-1]:
            self._points.append(new_point)
        self._current_r, self._current_c = int(r), int(c)
        self._dirty_turn = False
        return self

    def close(self):
        """闭合路径：将最后一个点连接回起点。"""
        if len(self._points) < 2:
            return self
        start = self._points[0]
        if self._points[-1] != start:
            self._points.append(start)
            self._current_r, self._current_c = start
        return self

    # ---- 内部方法 ----

    def _resolve_move_direction(self, direction) -> Tuple[int, int]:
        """解析 move 的方向，'along' 返回当前方向。"""
        if direction == 'along' or direction is None:
            if self._current_dir is None:
                raise RuntimeError("当前方向未定义，无法使用 'along'，请指定方向或先 turn()")
            return self._current_dir
        return _resolve_direction(direction)

    # ---- 构建 ----

    def build(self) -> 'TopoPath':
        """构建 TopoPath 实例。"""
        if not self._points:
            raise RuntimeError("路径为空，请先调用 .start()")
        if self._dirty_turn:
            import warnings
            warnings.warn("最后一次 turn() 之后没有 move()，旋转未产生新的路径点")
        return TopoPath(np.array(self._points, dtype=int), a=self.a, name=self.name)


# ============================================================
# TopoPath — 路径统一管理类
# ============================================================
class TopoPath:
    """
    拓扑路径统一坐标管理。
    唯一数据源是三角晶格坐标 (r, c)，直角坐标和 CST 表达式自动推导。
    """

    def __init__(self, path_lattice: np.ndarray, a: float, name: str = 'path'):
        """
        参数:
            path_lattice: (N, 2) 数组，每行是 (r, c) 三角晶格坐标
            a: 晶格常数 (mm)
            name: 路径名称，用于 CST 参数前缀（如 'p' → p1x, p1y, ...）
        """
        self.path_lattice = np.array(path_lattice, dtype=int)
        if self.path_lattice.ndim != 2 or self.path_lattice.shape[1] != 2:
            raise ValueError(f"path_lattice 形状应为 (N,2)，收到 {self.path_lattice.shape}")
        self.a = float(a)
        self.name = name
        # 预计算直角坐标（float，用于 matplotlib）
        self._xy = self._lattice_to_xy(self.path_lattice, self.a)

    # ---- 静态工具：坐标转换 ----

    @staticmethod
    def _lattice_to_xy(path: np.ndarray, a: float) -> np.ndarray:
        """(r,c) → (x,y)，与 path_loc_to_xy 完全一致"""
        r = path[:, 0].astype(float)
        c = path[:, 1].astype(float)
        x = c * a + r * (a / 2)
        y = r * (a / 2 * np.sqrt(3))
        return np.column_stack((x, y))

    @staticmethod
    def lattice_to_cst_expr(r: int, c: int) -> Tuple[str, str]:
        """
        (r,c) → CST 表达式字符串 (px, py)。
        生成的表达式可直接传入 app.para()，CST 会自动解析。
        简化规则：r=0 时 py='0'，r=0 时 px 不含 r 项。
        """
        r, c = int(r), int(c)
        # x = c*a + r*a/2
        if r == 0:
            px = f'{c}*a'
        elif c == 0:
            px = f'{r}*a/2'
        else:
            px = f'{c}*a+{r}*a/2'
        # y = r*a/2*sqr(3)
        py = '0' if r == 0 else f'{r}*a/2*sqr(3)'
        return px, py

    # ---- 属性与访问 ----

    @property
    def xy(self) -> np.ndarray:
        """直角坐标 (N, 2)，用于 matplotlib 预览"""
        return self._xy.copy()

    @property
    def lattice(self) -> np.ndarray:
        """三角晶格坐标 (N, 2)，每行 (r, c)"""
        return self.path_lattice.copy()

    def __len__(self):
        return len(self.path_lattice)

    def __getitem__(self, idx):
        return tuple(self.path_lattice[idx])

    def __repr__(self):
        pts = ', '.join(f'({r},{c})' for r, c in self.path_lattice)
        return f"TopoPath(name='{self.name}', a={self.a}, points=[{pts}])"

    # ---- CST 集成 ----

    def auto_define_cst_params(self, app, prefix: Optional[str] = None):
        """
        自动在 CST 中定义所有路径点的 px/py 参数。
        例如 path 有 3 个点，则创建 p1x,p1y, p2x,p2y, p3x,p3y。
        """
        pfx = prefix or self.name
        for i, (r, c) in enumerate(self.path_lattice):
            px, py = self.lattice_to_cst_expr(r, c)
            app.para(f'{pfx}{i+1}x', px)
            app.para(f'{pfx}{i+1}y', py)

    def get_cst_point(self, idx: int, prefix: Optional[str] = None) -> Tuple[str, str]:
        """获取第 idx 个点的 CST 参数名元组 ('p1x', 'p1y')"""
        pfx = prefix or self.name
        return (f'{pfx}{idx+1}x', f'{pfx}{idx+1}y')

    def get_cst_polygon(self, indices: List[int], prefix: Optional[str] = None) -> List[List[str]]:
        """
        获取指定索引点组成的多边形顶点列表（CST 表达式格式）。
        可直接传入 app.polyline(data, name)。
        """
        pfx = prefix or self.name
        return [[f'{pfx}{i+1}x', f'{pfx}{i+1}y'] for i in indices]

    # ---- 边界与范围 ----

    def get_bounding_box(self, margin_c: int = 1, margin_r: int = 1
                          ) -> Tuple[float, float, float, float]:
        """
        从路径自动推导边界范围（物理坐标）。
        返回 (xmin, xmax, ymin, ymax)。
        margin_c / margin_r: 在晶格坐标上的外扩格数。
        """
        r_min = self.path_lattice[:, 0].min() - margin_r
        r_max = self.path_lattice[:, 0].max() + margin_r
        c_min = self.path_lattice[:, 1].min() - margin_c
        c_max = self.path_lattice[:, 1].max() + margin_c
        corners = np.array([
            [r_min, c_min], [r_min, c_max],
            [r_max, c_min], [r_max, c_max],
        ])
        xy_corners = self._lattice_to_xy(corners, self.a)
        return (float(xy_corners[:, 0].min()), float(xy_corners[:, 0].max()),
                float(xy_corners[:, 1].min()), float(xy_corners[:, 1].max()))

    def get_array_range(self) -> Tuple[int, int, int]:
        """
        自动推导光子晶体阵列的复制范围。
        返回 (xup, yup, ydn)，对应原代码中的阵列重复次数。
        xup: 沿 +c 方向的重复次数
        yup: 沿 +r 方向（上半区）的重复次数 / 2
        ydn: 沿 -r 方向（下半区）的重复次数 / 2
        """
        r_vals = self.path_lattice[:, 0]
        c_vals = self.path_lattice[:, 1]
        xup = int(c_vals.max()) + int(abs(r_vals.max()) / 2) + 1
        yup = int(abs(r_vals.max())) + 1
        ydn = int(abs(r_vals.min())) + 1
        return xup, yup, ydn

    # ---- 区域多边形自动生成 ----

    def build_substrate_polygon(self, y_margin: str = 'e2',
                                  prefix: Optional[str] = None) -> List[List[str]]:
        """
        自动生成基板的 polyline 顶点（CST 表达式列表）。
        基板 = 路径上下各扩展 y_margin 的带状区域。
        上边界从左到右沿路径，下边界从右到左沿路径，首尾闭合。
        """
        pfx = prefix or self.name
        n = len(self.path_lattice)
        pts = []
        # 上边界（路径顺序，y + margin）
        for i in range(n):
            px, py = self.get_cst_point(i, pfx)
            pts.append([px, f'{py}+{y_margin}'])
        # 下边界（逆序，y - margin）
        for i in range(n - 1, -1, -1):
            px, py = self.get_cst_point(i, pfx)
            pts.append([px, f'{py}-{y_margin}'])
        # 闭合
        pts.append(pts[0])
        return pts

    def build_vpc_area_polygon(self, side: str = 'upper',
                                 y_margin: str = 'e2',
                                 prefix: Optional[str] = None) -> List[List[str]]:
        """
        自动生成 VPC-A/B 区域的裁剪多边形。
        side='upper': 上半区（路径 + 上边界 + 左上角 + 右上角）
        side='lower': 下半区
        """
        pfx = prefix or self.name
        n = len(self.path_lattice)
        pts = []
        if side == 'upper':
            # 路径从左到右 → 右上角 → 左上角 → 闭合
            for i in range(n):
                pts.append(list(self.get_cst_point(i, pfx)))
            # 右上角（最后一个点的 y + margin）
            px_last, py_last = self.get_cst_point(n - 1, pfx)
            pts.append([px_last, f'{py_last}+{y_margin}'])
            # 左上角（第一个点的 y + margin）
            px_first, py_first = self.get_cst_point(0, pfx)
            pts.append([px_first, f'{py_first}+{y_margin}'])
        else:  # lower
            for i in range(n):
                pts.append(list(self.get_cst_point(i, pfx)))
            px_last, py_last = self.get_cst_point(n - 1, pfx)
            pts.append([px_last, f'{py_last}-{y_margin}'])
            px_first, py_first = self.get_cst_point(0, pfx)
            pts.append([px_first, f'{py_first}-{y_margin}'])
        pts.append(pts[0])  # 闭合
        return pts

    # ---- 方向分析 ----

    def segment_directions(self) -> List[Tuple[int, int]]:
        """返回每段路径的方向向量 (dr, dc) 列表"""
        dirs = []
        for i in range(len(self.path_lattice) - 1):
            dr = self.path_lattice[i + 1, 0] - self.path_lattice[i, 0]
            dc = self.path_lattice[i + 1, 1] - self.path_lattice[i, 1]
            gcd = abs(int(np.gcd(dr, dc))) if (dr != 0 or dc != 0) else 1
            dirs.append((int(dr // gcd), int(dc // gcd)))
        return dirs

    def segment_angles(self) -> List[float]:
        """返回每段路径的物理角度（度）"""
        angles = []
        for dr, dc in self.segment_directions():
            x = dc * self.a + dr * (self.a / 2)
            y = dr * (self.a / 2 * np.sqrt(3))
            angles.append(float(np.degrees(np.arctan2(y, x))))
        return angles

    def is_straight(self) -> bool:
        """是否为直线路径（波导）"""
        return len(self.path_lattice) <= 2

    def has_bend(self) -> bool:
        """是否包含拐弯（天线）"""
        return len(self.path_lattice) > 2

    # ---- 预览绘图 ----

    def preview(self, ax=None, show_grid: bool = True,
                color: str = 'green', marker: str = 'o',
                linewidth: float = 2, markersize: float = 6,
                label: Optional[str] = None,
                lattice_rows: Optional[Tuple[int, int]] = None,
                lattice_cols: Optional[Tuple[int, int]] = None):
        """
        matplotlib 预览：画出路径 + 可选晶格背景。
        返回 (fig, ax)。
        """
        if ax is None:
            fig, ax = plt.subplots(figsize=(10, 8))
        else:
            fig = ax.figure

        # 晶格背景（可选）
        if show_grid:
            try:
                from mesh_grid.tri_grid import plot_triangle_grid, build_triangle_lattice
                if lattice_rows is None:
                    r_min = self.path_lattice[:, 0].min() - 2
                    r_max = self.path_lattice[:, 0].max() + 2
                    lattice_rows = (r_min, r_max)
                if lattice_cols is None:
                    c_min = self.path_lattice[:, 1].min() - 2
                    c_max = self.path_lattice[:, 1].max() + 2
                    lattice_cols = (c_min, c_max)
                h = self.a * np.sin(np.deg2rad(60))
                r = self.a / np.sqrt(3)
                offset = (self.a / 2, h - r)
                plot_triangle_grid(lattice_rows, lattice_cols, self.a,
                                   offset=offset, show_labels=False, show_points=False, ax=ax)
            except ImportError:
                pass  # 没有 mesh_grid 就只画路径

        # 路径
        lbl = label or f'{self.name} ({len(self)} points)'
        ax.plot(self._xy[:, 0], self._xy[:, 1], color=color, lw=linewidth,
                marker=marker, markersize=markersize, label=lbl)

        # 标注拐点坐标
        for i, ((r, c), (x, y)) in enumerate(zip(self.path_lattice, self._xy)):
            ax.annotate(f'({r},{c})', (x, y), textcoords="offset points",
                        xytext=(8, 8), fontsize=8, color=color)

        ax.set_aspect('equal')
        ax.set_xlabel('x (mm)')
        ax.set_ylabel('y (mm)')
        ax.set_title(f'TopoPath: {self.name}  (a={self.a} mm)')
        ax.legend()
        ax.grid(True, alpha=0.3)
        return fig, ax

    # ---- 构建器入口 ----

    @staticmethod
    def builder(a: float, name: str = 'path') -> TopoPathBuilder:
        """创建声明式构建器"""
        return TopoPathBuilder(a, name)

    @staticmethod
    def from_lattice(points: List[Tuple[int, int]], a: float,
                     name: str = 'path') -> 'TopoPath':
        """从 (r,c) 列表直接创建（兼容旧代码）"""
        return TopoPath(np.array(points, dtype=int), a=a, name=name)
```

### 9.4 与原代码的逐点对应验证

| 结构 | 原代码 path | DSL 写法 | DSL 生成的 path | 一致性 |
|------|------------|---------|----------------|--------|

| CST py3 (120°) | `py3 = y1*a/2*sqr(3) = 7a√3` | `p3y = lattice_to_cst_expr(14,4) = '14*a/2*sqr(3)' = 7a√3` | `7a√3` | ✓ |

### 9.5 扩展接口说明

| 方法 | 用途 | 何时用 |
|------|------|--------|
| `builder(a)` | 创建构建器 | 所有新模型 |
| `.start(r,c)` | 设置起点 | 构建器第一步 |
| `.move(steps, dir)` | 沿方向走 N 格 | 直线路径段 |
| `.turn(angle)` | 旋转当前方向 | 拐弯处 |
| `.line_to(r,c)` | 直接到指定点 | 复杂路径/功分器 |
| `.close()` | 闭合回起点 | 环形结构 |
| `.build()` | 生成 TopoPath | 构建结束 |
| `path.xy` | 直角坐标 | matplotlib 绘图 |
| `path.preview()` | 自动预览（含晶格背景） | 建模前检查 |
| `path.auto_define_cst_params(app)` | 自动定义 CST 参数 | CST 建模第一步 |
| `path.get_cst_point(i)` | 获取第 i 点的 CST 参数名 | 构建 polyline 顶点 |

| `path.get_array_range()` | 自动推导阵列复制范围 | 替代手动 xup/yup/ydn |
| `path.segment_angles()` | 每段物理角度 | 调试/验证 |
| `path.is_straight()` / `has_bend()` | 判断波导/天线 | TopoModeler 智能推断 |
