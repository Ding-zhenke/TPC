## 2. 核心概念（AI 必须理解）

### 2.1 拓扑光子晶体基础



* **VPC（Valley Photonic Crystal）**：能谷光子晶体，通过打破空间反演对称性实现拓扑边界态

* **VPC-A / VPC-B**：两种拓扑相，由三角孔的大小 / 方向区分。A 相和 B 相的界面支持拓扑边界态传导

* **超元胞（supercell）**：由 6 个三角孔组成的六重对称单元（一个大三角参考 + 一个小三角孔，旋转 120° 复制两次）

* **晶格常数 a**：相邻超元胞中心间距，本工程固定 `a = 0.2425 mm`（对应～300 GHz）

* **硅片厚度 h**：`h = 0.25 mm`

* **三角孔比例**：大孔 `0.65a`，小孔 `0.35a`（VPC-A 和 VPC-B 的大 / 小孔互换）

### 2.2 AB 型 vs BA 型



|          | VPC-A（上半区）         | VPC-B（下半区）         |
| -------- | ------------------ | ------------------ |
| **AB 型** | 大三角孔 `l1=0.65a` 朝上 | 小三角孔 `l2=0.35a` 朝上 |
| **BA 型** | 小三角孔 `l1=0.35a` 朝上 | 大三角孔 `l2=0.65a` 朝上 |

关键：`l1`/`l2` 的赋值在 AB 和 BA 型中是**互换**的。建模时 `l=['l1','l2']`，循环中 `l[i]` 和 `l[1-i]` 实现互补。

### 2.3 拓扑边界态传导路径



* 波导：VPC-A 和 VPC-B 的界面（直线路径）支持边界态单向传导

* 天线：边界态传导到辐射体（圆柱 / 椭圆 / GRIN 透镜）后向外辐射

* 拐弯：拓扑边界态可以沿任意路径拐弯（120°/180°/240°），辐射体角度对应波束方向

### 2.4 频率范围



* 工作频段：\~300 GHz（毫米波 / 太赫兹）

* 仿真频率范围：波导 300-380 GHz，天线 280-380 GHz

* 监视器频率：`np.arange(310, 322, 2)` → 310, 312, ..., 320 GHz

## 4. 标准工作流

### 4.1 新建模型的 10 步流程



```
第1步：导入库（§3.1 模板）

第2步：定义参数（a, h, l1, l2, x, y, 探针尺寸, 波导尺寸）

第3步：matplotlib 预览拓扑结构（调用 preview\_topology 或 plot\_power\_divider）

第4步：打开 CST：app = setup('tmp.cst')

第5步：传递参数到 CST（app.para 批量）

第6步：计算区域坐标点（px/py/xmax/ymax 等）

第7步：添加材料 + 设置频率

第8步：建模（按顺序！）：

&#x20;      基板 → VPC区域裁剪 → 光子晶体阵列 → 探针/馈电 → 辐射体 → 端口 → 整合

第9步：监视器 + 求解器配置

第10步：保存 .cst
```

**建模顺序不可乱**：光子晶体必须在 VPC 区域之后（要 intersect 裁剪）；探针必须在晶体之后（要 add 整合）；端口必须在所有几何完成后。

### 4.2 修改已有模型参数



1. 打开对应 notebook

2. 找到第 2 个 code cell（`#添加变量` 注释处）

3. 修改参数值

4. **注意**：`x` 和 `y` 是 numpy 数组，长度决定区域分段数，修改长度会影响后续 `for i in range(len(x))` 循环和区域坐标公式

5. 重新运行全部 cell（Kernel → Restart & Run All）

6. 检查保存路径是否正确

## 7. 常见问题与调试

### 7.1 CST 建模报错



| 现象                     | 原因                                   | 解决                                               |
| ---------------------- | ------------------------------------ | ------------------------------------------------ |
| `substract` 报错 "对象不存在" | 布尔运算顺序错，或名称拼写错                       | 检查 name 是否一致，确认前置 add/extrude 已执行                |
| `pick_face` 后面编号无效     | 面编号是 CST 内部的，结构变了编号会变                | 在 CST 界面手动拾取确认面编号，或用 pick\_face 替代方案             |
| 保存后打开 CST 报历史树错误       | VBA 表达式有语法错误（如 `sqr` 写成 `sqrt`）      | 检查所有 `app.para` 的字符串表达式，CST 用 `sqr()` 非 `sqrt()` |
| 光子晶体阵列不全               | `repetitions` 表达式计算结果不对              | 检查 `xup`/`yup`/`ydn` 的 para 是否正确传递               |
| 端口位置不对                 | `pick_face` 编号错，或波导 translate 后面编号变了 | 重新在 CST 中确认                                      |

### 7.2 Python 报错



| 现象                                           | 原因                | 解决                                             |
| -------------------------------------------- | ----------------- | ---------------------------------------------- |
| `ModuleNotFoundError: No module named 'cst'` | CST Python 库路径未配置 | 检查 `cst_solver/config.py` 中 `CST_INSTALL_PATH` |
| `FutureWarning: tri_lib 已迁移`                 | 用了旧兼容入口           | 改用 `from mesh_grid.tri_grid import ...`        |
| `FileNotFoundError: tmp.cst`                 | 工作目录下没有模板         | 用绝对路径，或先复制模板到工作目录                              |
| matplotlib 中文乱码                              | 字体未配置             | `mesh_grid` 包导入时会自动配置，确保先导入                    |

### 7.3 仿真结果异常



| 现象              | 可能原因                            |
| --------------- | ------------------------------- |
| S21 极低（< -30dB） | 拓扑相弄反了（AB/BA 互换），或探针没对准边界态      |
| S11 很高（> -5dB）  | 探针阻抗不匹配，调整 lf/wf 参数             |
| 远场方向图畸形         | 辐射体形状 / 位置不对，或 Farfield 监视器频率不对 |
| 结果不收敛           | 稳态限制 `-30` 不够，或网格太粗             |

## 8. 编码规范（AI 写代码时必须遵守）

### 8.1 必须遵守



1. **CST 表达式用&#x20;**`sqr()`，不是 Python 的 `sqrt()`。所有传入 `app.para()` 的字符串表达式中，平方根写 `sqr(3)`。

2. **方法名是&#x20;**`substract`（非 `subtract`），这是库中的拼写，不要 "纠正"。

3. **建模顺序固定**：基板 → VPC 区域 → 晶体阵列 → 探针 → 辐射体 → 端口 → 整合。

4. **z 轴居中**：所有 extrude 后需 `translate(['0','0','-h/2'])` 使结构中心在 z=0。

5. **保存用&#x20;**`include_results=False`：避免文件过大。

6. **路径用 raw string**：`r'D:\path\to\file.cst'` 或正斜杠。
