## 〇、TPC 库代码风格规范（修改 TPC 库时必须遵守）

> 以下规范基于对 `cst_solver/` 和 `mesh_grid/` 现有代码的实际梳理。所有对 TPC 库的修改必须与此风格一致。

### 0.1 文件头格式

```python
# -*- coding: utf-8 -*-
"""
模块标题
========
模块功能简述

@author: PC
"""
```

### 0.2 类设计

- 所有建模功能类命名为 `XxxMixin`，通过多继承聚合到 `setup` 主类
- 新功能优先写在 `topo_modeler/` 新包中，**不修改** `cst_solver/` 核心 Mixin
- 确需修改 TPC 库时，在对应 Mixin 中追加方法，不删除/重命名已有方法

### 0.3 方法命名（双接口原则）

- 提供**旧名**（与 notebook 中调用一致，如 `para`, `square`, `substract`）
- 同时提供**蛇形命名新名**（如 `set_parameter`, `create_brick`），新名内部调用旧名
- 新写的方法直接用蛇形命名，不需要旧名别名（除非有兼容需求）

### 0.4 Docstring 格式

```python
def method_name(self, param1, param2='default'):
    """
    方法功能一句话描述

    :param param1: str, 参数1描述
    :param param2: str, 参数2描述，默认 default
    :return: 返回值类型及描述
    """
```

### 0.5 VBA 命令拼接

- 用 f-string 拼接 VBA 命令
- 通过 `self.cst_file.model3d.add_to_history("操作描述", vba_string)` 注入
- VBA 内部用双引号，Python f-string 外层用三引号

### 0.6 其他

- 缩进：4 空格
- 字符串：双引号为主
- 编码声明：每个 .py 文件第一行必须有 `# -*- coding: utf-8 -*-`
- 不使用 `from xxx import *`（`__init__.py` 中导出除外）

## 阶段 5：GRIN 透镜 + GRINLensAntenna 模板

**阶段目标**：统一 GRIN 透镜的两种建模方式（hexagon 直接生成 / DXF 导入），完成最大类模板（覆盖 40 个 notebook）。

### 步骤 5.1：builders/lens.py

**功能**：
```python
def build_grin_lens(app, method='hexagon', **params):
    """
    GRIN 渐变折射率透镜构建器，统一两种建模方式：
    - method='hexagon': 直接用 hexagon() 循环生成六边形柱（33 个 notebook 用）
      参数：hex_size, layers, inner_radius, outer_radius, d0, origin, orientation
    - method='dxf': 从 DXF 文件导入（35 个 notebook 用）
      参数：dxf_path, component, material, height, translate
    内部根据 method 分支，对外统一接口。
    返回 lens 实体名称。
    """
```

**hexagon 方式内部**：
1. 调用 `HexLib` / `HexGridVisualizer` 生成六边形网格
2. 遍历每个六边形，按距离计算半径（渐变）
3. 调用 `app.hexagon()` 生成
4. `add()` 合并所有六边形
5. `mirror()` 镜像到全平面

**dxf 方式内部**：
1. 调用 `app.dxf_import(dxf_path, ...)`（TPC 库已有方法）
2. `translate()` 定位
3. `substract()` 挖空

**验证**：两种方式生成的透镜几何形状一致（在相同参数下）。
