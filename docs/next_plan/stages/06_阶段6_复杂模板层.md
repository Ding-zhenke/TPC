## 3. 任务清单

### 3.1 LensBuilder（模块 4.1）

两种构造方式：

| `method` | 做什么 |
|---|---|
| `'dxf'` | 从 DXF 导入透镜轮廓 |
| `'hexagon'` | 按六边形晶格生成（GRIN 渐变） |

### 3.2 GRINLensAntenna 模板（模块 4.2）

组装 `TopoModeler` + 透镜 + 参数 + 端口 + 求解器，一个类 = 一个器件。

## 4. ⚠️ 开工前必须补齐的规格缺口（06 §14.1）

06 对这两块**只给了「做什么」，没给「怎么做」和「怎么验证」**，
直接开工必然反复试错。以下每条都要先补成**可执行的签名 + 取值域 + 验收判据**：

| 缺口 | 计划里写的 | 库里的真实情况 | 需要补什么 |
|---|---|---|---|
| `method='dxf'` 的参数 | `dxf_path, component, material, height, translate` | `cst_solver.import_dxf()` 只收 `filename, add, HealSelfIntersections, ...`，**没有** `component` / `material` / `height` / `translate` | 补「导入后如何指定组件 / 材料 / 高度」的具体 VBA 步骤 |
| `method='hexagon'` 的公式 | 「遍历按距离算半径」 | 无 | 补**半径-距离公式**、层数定义、`inner_radius` / `outer_radius` 的确切含义与单位 |

**参考数据来源**：
- 透镜相关的旧 notebook 约 **68 个**（hexagon 33 + dxf 35）
- 旧 06 曾把透镜覆盖写成「约 40 个 notebook」，与它自己的 33+35 矛盾，已统一为 **68**
