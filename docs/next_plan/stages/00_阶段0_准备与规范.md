## 1. 阶段目标

建立包结构和代码规范，**不写功能代码**。这一阶段的价值全在后面：
它决定了整个项目是「一个有纪律的库」还是「又一堆 notebook 脚本」。

## 2. 任务清单

### 模块 0.1 包结构搭建

| 项 | 内容 |
|---|---|
| 新建包 | `topo_modeler/`（建模引擎）、`topo_templates/`（端到端模板） |
| 包入口 | 各自的 `__init__.py`，导出公开符号并维护 `__all__` |
| 打包配置 | 根目录 `pyproject.toml`，支持 `pip install -e .`，免去 `sys.path.append` |
| 旧入口归档 | `tri_lib.py` / `hexlib.py` / `cst_solver.py` → `archive/compat/*_shim.py` |

### 模块 0.2 代码风格规范

| 规范 | 内容 |
|---|---|
| docstring | Google/Numpy 风格**中文**，含参数 / 返回值 / 说明 |
| 类型标注 | CST 里的长度、角度都是**表达式字符串**，故写 `float | str` |
| 命名 | 新 API 一律 `snake_case`；CST/VBA 风格旧名保留为**别名**（如 `create_brick` ↔ `square`） |
| 格式 | 4 空格缩进；文件头 `# -*- coding: utf-8 -*-` |
| 执行通道 | `add_to_history(日志名, vba)` 是**唯一**执行通道 |
| 复合命令 | 多条 VBA 用 `log_flag=0` 拼成**一次**历史，保持历史树干净 |
| 错误通道 | **禁止**用 `print` 当错误通道，用异常或返回值 |
