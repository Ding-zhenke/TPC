## 3. 任务清单

### T1 实体级几何对比（🔴 本阶段核心判据）

**做什么**：把本库生成工程与参考 `AB_feed.cst` **逐实体**比对 bounding box / 体积。

**为什么**：参数吻合不代表布尔序列、绕向、阵列范围都对。
06 的判据是「**关键尺寸偏差 < 0.1%**」，只有实体级比对能坐实。

**怎么做**：
- 用 CST API 打开两个工程，列出实体名 + bounding box（`min/max` 六个分量）；
- 建立实体名映射（两边命名约定不同，不能按名字直接 join）；
- 对每对实体算六个分量的相对偏差，输出偏差表。

**验收**：所有关键实体的尺寸偏差 < 0.1%；命名差异单独列表说明。

**预估**：一个 CST 会话，1–2 h。

### T2 路径起点差一格：决策 + 修正（🟡 需决策）

| | 起点 | 终点 |
|---|---|---|
| 本库 `p1x` / `p2x` | `-0.2425`（= **−a**） | `4.365`（= 18a） |
| 参考 `px1` / `px2` | `0` | `4.365`（= 18a） |

终点一致，但本库起点早了一个晶格常数：本库路径 `c ∈ [-1, 18]`（19 格），参考 `c ∈ [0, 18]`（18 格）。
**后果**：基板与晶体阵列在 x 方向**比参考长一格**。

**成因**：`StraightWaveguide.__init__` 的 `start(0, -1)` 配 `.move(length + 1, 'c')`；
原注释只校验了终点（"终点 c = -1 + (length+1) = length"），**没校验起点**。

**待决策**：改成 `start(0, 0) + move(length, 'c')` 与参考对齐，还是起始多一格是有意为之（例如为馈源留位）？
**改前必须确认** —— 它会整体改变模型长度。

### T3 `l1`/`l2` 按实体核对

参数名与参考相反（本库 `l1` = 大孔）。`crystal.py` 已在逻辑上补偿
（AB 分支取 `hole_sizes=[small, large]`，`up_hole=hole_sizes[i]`、`dn_hole=hole_sizes[1-i]`）。
需用**实体几何**证明补偿正确，而非按名字比参数。

**验收**：参考历史树的 `tri_up_A→l1(小)`、`tri_dn_A→l2(大)`、`tri_up_B→l2(大)`、`tri_dn_B→l1(小)`
在本库生成工程中对应实体的孔尺寸分配一致。

### T4 核验 `_create_farfield_monitor()`

它仍手写 `With Farfield` VBA（违反 WORKFLOW §2），正确性**未验证** ——
因为默认 `monitors=('E',)` 不走该分支。

**怎么做**：实测正确的远场监视器 VBA（大概率应是 `Monitor` 对象 + `.SetDimensionType "Farfield"`），
核验后给 `cst_solver` 补封装，再回来改 builder。

### T5 `unit_antenna` 同源隐患

`unit_antenna.py:122` 用同一套 `path.get_array_range()`，与已修的 `StraightWaveguide` **同源**。
**未验证、未修改** —— UnitAntenna 是含拐弯的路径，需先确定其参考基准再决定阵列范围取值。

### T6 S 参数谐振峰 < 1 GHz（⚠️ 需跑求解器）

**前置**：T4、T6。

### T8 VPC 区域语义决策（🟡 需决策）

参考 `AB_feed.ipynb` 的 VPC-A 是「三角形区域 + `insert` / `intersect`」造出来的，
而本库 `build_vpc_regions()` 实现的是「路径上/下半区带状区域」。**两者不是同一个几何**；
且参考 notebook 里 VPC-A 实际落在 **`y < 0` 半平面**（`vpca_up/dn` 的 up/dn 指**三角形朝向**，不是上下半区）。

本轮修 CCW 绕向时把拐弯路径的带状区域改成了「真正沿路径的带」（顶点数 `N+3 → 2N+1`），**使差异更明确**。

**待决策**：以参考工程为准复刻旧造法，还是以新带状语义为准并重新定基线？

### T9 面编号方案落地

方案已定（双通道）、事实已验（§2.4），剩下实现：

| 端口面类型 | 方案 |
|---|---|
| 轴对齐矩形面（直波导两端、天线入口） | `create_waveguide_port_free(...)`（`Coordinates "Free"` + `Xrange/Yrange/Zrange`） |
| 非轴对齐面（拐弯 / 扭转后的端面） | 正算出面上一点 → `get_face_id_from_point()` → `pick_face()` + `add_port()` |

**改动**：`topo_modeler/builders/port.py` 的硬编码 `'10'` / `'22'`。
