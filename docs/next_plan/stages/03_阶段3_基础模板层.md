### `build_all()` 的流水线（11 步）

```
1 参数定义 → 2 材料 → 3 基板 → 4 VPC 区域 → 5 晶体阵列 → 6 馈源 →
7 空心波导 → 8 mirror 到右端 → 9 端口 → 10 整合 → 11 求解器配置
```

> 步骤 2「材料」是本轮补上的（此前缺失，导致任何模板跑 `build_all()` 都必失败）。

### 参考模型的默认参数（必须与参考工程一致）

| 参数 | 值 | 说明 |
|---|---|---|
| `a` | 0.2425 mm | 晶格常数 |
| `h` | 0.25 mm | 硅片厚度 |
| `l1` / `l2` | 0.65a / 0.35a | ⚠️ **与参考工程命名相反**，见下 |
| `e1` / `e2` | `a/2` / `a·√3/2` | 三角晶格半间距 |
| `x0` / `wf1` / `lf1,lf2,lf3` | 4 / 0.2 / 0.2, 3.0, 0.2 | AB 型椭圆探针 |
| `wg_a` / `wg_b` / `wg_t` | 0.7312 / 0.3756 / 0.2 | 铜波导内腔与壁厚 |
| `fmin` / `fmax` | 300 / 380 GHz | 工作频段 |

> ⚠️ **`l1`/`l2` 命名陷阱**：参考工程 `AB_feed.cst` 的参数表是
> `l1=0.35a`（**小**孔）、`l2=0.65a`（**大**孔）；本库定义
> `l1=large_hole_ratio*a=0.65a`、`l2=0.35a` —— **两者互换**。
> `builders/crystal.py` 已在逻辑上补偿，故**几何应一致而参数名相反**。
> **逐项对比不能按名字 naive 比 `l1`/`l2`**，须按实体几何核对（阶段 4 T3）。
