## 1. 阶段目标

让**晶格坐标只有一个数据源**。这是整个项目的技术地基：
旧 notebook 里每个模型都要手推 `x = c·a + r·a/2`、`y = r·a·√3/2`，
手工推导极易出错且无法复用。

## 2. 任务清单

### 模块 1.1 TopoPath 落地

| 能力 | 说明 |
|---|---|
| `TopoPath` + `TopoPathBuilder` | 声明式路径 DSL：`.start(r,c)` / `.move(n,'c')` / `.turn(...)` / `.line_to(...)` / `.build()` |
| `path_loc_to_xy()` | **坐标换算唯一基准**，任何新公式必须与它一致 |
| 直角坐标推导 | 路径点 → `(x, y)` 列表 |
| CST 表达式生成 | `auto_define_cst_params(app, prefix)` 自动定义 `p1x/p1y/...` |
| 多边形生成 | `build_substrate_polygon()`、`build_vpc_area_polygon(side=...)` |
| 阵列范围 | `get_array_range()` → `(xup, yup, ydn)` |
| 空间选择 | 线上/线下/多边形内的点集筛选 |
| 预览 | `preview()`（matplotlib 叠加晶格背景） |
| 导出 | DXF 导出 |

## 4. 验证

```bash
python -m pytest mesh_grid -q      # → 16 passed
```

**绕向必须由单测钉住**：`build_substrate_polygon()` 与
`build_vpc_area_polygon(side='lower')` 曾生成**顺时针**多边形，而调用方统一用
「CCW + 内部 `translate -h/2`」，导致基板/VPC-B 与晶体在 z 上**差一个 `h`**，
布尔求交得空集且 CST 不报错。第 16 项单测用**有向面积**把绕向钉死。
